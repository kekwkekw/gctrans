# 첫 홈 readiness 표적 검사

```powershell
dotnet build tests/HeaderEntryTests/HeaderEntryTests.csproj -c Release
dotnet tests/HeaderEntryTests/bin/Release/net9.0/HeaderEntryTests.dll translations/ko/ui/bindings.json
```

현재 candidate DLL의 관리형 상태 전이와 실제 PE의 native adapter 호출 연결을 검사한다. delayed active/동일 source/비활성 alive/소멸·재사용·target 교체/폰트 publish/반복 edge/재열기·재시작을 구분한다. 합성 identity/CPU PASS는 실제 owner·glyph·화면 PASS가 아니다. 실제 최초 홈과 정상 재시작, 안전한 종합 UI 순회는 별도 native 근거로 남긴다.

종합 순회에서 확인한 Filter SelectAll/Deselect의 독립 control 활성 전환도 같은 표적 검사에서 다룬다. 현재 typed button/TMP와 literal producer를 재검증하며 기존 active/preferred-size/glyph/ownership 검사를 완화하지 않는다. Filter 임시 상태는 적용·저장 없이 취소하여 원래 화면 상태를 보존한다.
