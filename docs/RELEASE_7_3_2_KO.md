# GCMod 7.3.2 — 7.2.1에서 직접 업데이트

7.2.1 사용자는 `GCMod-7.3.2-ko-update.zip`으로 바로 업데이트할 수 있다. 7.3.0·7.3.1 선행 설치는 필요하지 않다. 업데이트 ZIP은 일부 버전 차이만 담은 delta가 아니라 최신 DLL과 전체 runtime 번역 데이터를 포함한다. 신규 설치에는 `GCMod-7.3.2-ko-full-win-x64.zip`을 사용한다.

## 7.2.1 이후 포함한 변경

* 게임 옵션에서 일반·CG 대화창 불투명도, 글자 가독성 보정, 30/60 FPS를 조절한다. 미리보기·저장·폐기와 CG 세 번째 줄 배치를 보완했다.
* F5·F6·F7의 표시 설정은 게임 옵션으로 이동했다. F3·F8·F10 등의 GCMod 전용 단축키도 제거했으며 설정·번역 파일 편집 후에는 게임을 재시작한다.
* 정상 시작 시 패치 로드 완료 카드는 표시하지 않고 초기화·UI 데이터·폰트 오류가 있으면 오류 카드를 표시한다.
* 전투의 필요 열정·필요 HP·남은 CT, 던전 시즌 안내, ADF 응원 편성·점수 배율·권장 전투력·수령 기한 등 값이 들어간 문구를 보완했다. 점수 알림은 이름을 보존해 `이름이/가 지구에서`로 표시한다.
* 로그인 보너스 상자 두 문구와 월 가격, 응원 설명·배지를 보완했다. 상점 3종·회상 4종·지구/전역/근교 7종의 이미지와 앞선 전투 안내 이미지 보완을 포함한다. 지구의 글자 그라데이션·테두리는 통일했고 원본 알파를 보존했다.
* 전체가 영문 표기인 원문은 대소문자·공백·변수까지 그대로 유지한다. Normal·Hard도 원문 그대로이며, 기존 96종 정리와 재유입 방지를 포함한다.
* 현재 main에서 검수·반영된 시나리오·Master·Names 데이터를 포함한다. 이 릴리스 준비에서는 번역 정본·Knowledge·Names·Novel 본문·이미지 bytes를 추가로 변경하지 않았다.

동적 문구와 옵션 보완에는 새 DLL이 필요하다. 번역 데이터의 자동 갱신은 DLL·폰트·로더·사용자 설정을 갱신하지 않는다.

## 기존 7.2.1 설치 업데이트

1. 게임을 종료하고 `BepInEx/plugins/GCMod/`와 `BepInEx/config/GCMod.cfg`를 게임 폴더 밖에 백업한다.
2. 업데이트 ZIP을 임시 폴더에 푼다.
3. 풀린 `BepInEx/plugins/GCMod/`의 내용만 게임의 같은 위치에 덮어쓴다. 기존 로더·Utility·폰트는 계속 사용한다.
4. **기존 `BepInEx/config/GCMod.cfg`는 그대로 둔다.** cfg가 없을 때만 ZIP의 기본 cfg를 복사한다. 이전 키와 주석도 강제 삭제하지 않는다.
5. DMM GAME PLAYER 또는 기존 DMM 실행 경로로 게임을 시작한다. 새 옵션은 게임 옵션에서 확인한다.

공식 설치 도구도 기본적으로 기존 cfg bytes를 보존한다. 업데이트를 위해 한국어 기본 프로필 재설정 옵션을 사용할 필요는 없다. 새로 추가된 cfg 항목은 BepInEx의 기본값으로 등록된다.

## 구성과 검증 범위

현재 package는 UI 14,052쌍, Master 34,388키(원문 유지 포함), Novel 1,939파일, 이미지 대상 179개를 포함한다. 전체 게임 완역·전수 실기 수가 아니다.

7.3.2는 main의 PR #73 기능을 유지하면서 플러그인·어셈블리 버전과 시작 로그를 7.3.2로 맞춘다. 7.2.1 공식 full ZIP의 SHA-256은 `44a496317f8d4a1fb51b505e07fc7a2ab4f26a7e7f1e83e20c40b75145ad06cc`이다. 새 full 설치본의 로더·.NET 런타임·Utility·폰트 및 타사 소스는 이 검증된 배포본과 같은 bytes를 재사용한다. 고지는 현행 구성 요소별 목록으로 선택한다. 빌드에 사용하는 BepInEx 핵심 참조 5개와 Utility·폰트도 7.2.1 배포본과 동일하다.

Release 빌드, 기존 회귀 검사, full/update 구성·해시와 7.2.1 → 7.3.2 설치·설정 보존을 검사한다. 최종 결과·릴리스 기준 commit·배포 파일 해시는 릴리스의 `release-verification.json`과 `SHA256SUMS.txt`에 기록한다. 새 설치본으로 실제 순정 설치·게임 재시작·전투 전체 절차를 반복했다는 뜻은 아니다. 기존 실제 표시 확인과 남은 화면 범위는 [표시 누락 보완 기록](UI_OMISSIONS_20261119_KO.md)을 따른다.

로컬 Release 빌드는 오류 0개·기존 경고 6개이며 DLL 파일 버전은 7.3.2.0이다. SHA-256은 `37402bf49a4d34821d1b7278148066f09fe6582504f3e7654454fe13102aeaf7`이다. main과 443개 메서드의 IL·지역 변수·예외 처리 구조를 비교했고 `Plugin.Load`의 시작 로그 버전 문자열만 달랐다. 기존 Python 166개 및 C# 검사 4개를 통과했다.

7.2.1 공식 ZIP의 2,360개 파일을 해시 확인한 격리 설치 구성에서 기본 cfg와 BOM·CRLF·맞춤 값이 있는 cfg 두 경우를 검사했다. 두 경우 모두 최신 payload가 설치되고 cfg bytes와 로더·의존성·고지 253파일이 유지됐으며, 롤백 후 이전 파일 bytes도 복원됐다. 7.3.0·7.3.1 설치본은 이 경로의 입력에 쓰지 않았다. 이는 파일 설치·설정 보존 검증이며 실제 게임 실행은 아니다.

2026-11-20 배포 고지 정정: 최초 full·sources-notices 조립에서 과거 고지 전체를 복사한 오류를 바로잡았다. 퇴역한 고지와 귀속 문구를 제외하고 고지 목록·패키지 manifest·검증 기록·체크섬을 갱신한다. DLL·로더·Utility·폰트·번역 데이터와 update ZIP은 정정 전후 같은 bytes다. 원본 태그는 유지하며 포장 수정 commit을 별도로 기록한다. 이전 설치 경로의 결과와 현재 배포 고지 정합성은 구분한다.

전체 설치본과 업데이트본은 게임 본체·생성된 interop/cache·로그·인증 정보·개인 설정을 포함하지 않는다. 원문과 실패 근거는 계속 로컬에 보존한다. 타사 라이선스와 대응 소스는 별도 sources-notices ZIP을 함께 배포한다.
