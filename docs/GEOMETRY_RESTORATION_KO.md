# B46 후속 geometry 복원

기준은 `97bcf19b455e2f36288767d14245b0a7575ed4b2`다. `RESTORATION_CLOSEOUT_KO.md`의 두 미복원은 B46 결과 이력이며 원본 보고/로그는 보존한다. 이번 candidate의 실제 최종 source/DLL/선택/profile·CPU·native·Stable 원복과 전체 판정은 함께 반환한 실행 보고를 사용한다. 구현만으로 전체 수락이나 영구 설치 권한을 만들지 않는다.

Filter 전체 선택은 현재 interop의 `Gc.FilterPopup._selectAllButton`과 unique exact owner-relative path/직접 InertButton TMP로 증명한다. Reset/Deselect의 다른 필드를 빌리지 않는다. 기존 preferred-size driver capture/configuration과 구동 축의 현재 preferred dimensions만 허용하고 비구동 축·owner·selection/control·fitter 교체와 clipping 검사는 보존한다. 원래 button/delegate/layout setter를 쓰지 않는다. 유한한 mesh/layout 정착 뒤 표시를 평가한다.

교환 상점 안내문은 `Gc.Shop.ShopTopController`의 현재 typed view/model/Exchange view/tab과 직접 `Tab_Child_Header/Text_Message`다. 동일 문구의 명경 변환 popup, Shop title, Footer와 다른 역할이다. UI21에서 동일 JP/KO가 배치용 leaf 밖에서 정상 정착한 과거 근거를 보존한다. 현재 full rendered quads는 정확히 이 header row에 포함되어야 하며 active clip/mask, 지원 shader/material/channel, 전체 문자열, 형제 controls와의 비침범을 검사한다. 큰 ancestor를 찾거나 Footer의 ink 축소를 적용하지 않는다. unknown shader/stencil clip과 실제 잘림은 거부한다.

수락 문구·공백·폰트크기·rect는 변경하지 않는다. source-only 수정이며 complete restored JSON/명시62-table profile은 B46과 같다. 적용 단위는 새 DLL+완전 JSON+명시 profile+actual current/pending 선택이다. 구 r2/main loader의 producer JSON 거부와 LKG 계약은 그대로다. PackageRoot만 바꾼 partial 전환을 복원 완료로 부르지 않는다.

같은 배치의 native에서 캐시된 Shop 탭 복귀 시 교환 가능 배지가 원문으로 갱신되지만 cell.Setup/스크롤 이벤트 없이 기존 유한 재관측 기간이 끝난 경로를 확인했다. 기존 검증된 SetupCurrentTabView callback에서 현재 page/view/model/tab/Exchange product view를 다시 확인하고 기존 bounded current-visible batch만 재준비한다. 새 hook·callback 재호출·상시 전체 오브젝트 scan은 없다. 배지의 source/숫자/제어/geometry/ownership 보호와 원래 2초·4회 batch 상한은 유지한다. 최초 BF750 정착/탭 복귀 실패와 후속 DLL 결과는 revision별로 구분한다.

전체379/377와62/101은 audit 범위이며 runtime gate가 아니다. 조건부110개는 exact role/current native state별로 분류하고 sourceCPU2(`CV：非公開`, popup 닫기)의 기존 근거·관측 제한을 유지한다. 최종 B46에서 load가 없는 `slim_mMuseumBlocks`는 이전 Museum scoped load 근거가 있고 fields `ml_name[]`, `ml_open_message[]` 43 mapping이다. 한 table load를 모든 field 표시 PASS로 확대하지 않는다.

상시 승인된 trial은 fresh 외부 backup/CAS로 현재 nonempty Stable store와 선택을 보존한 뒤 수행하고 r2 Stable로 정확히 복귀한다. 기존 store-absent helper를 적용하지 않는다. 기본 opt-in/CheckUpdate/UiRequests OFF, XUnity OFF이며 영구 승격/공개 쓰기/소비·출격·수령·변환·설정/팀 저장은 별도 권한으로도 이번 작업에서 수행하지 않는다. DMM 인증이 만료되면 사용자 재인증이 필요하며 token/인증 URL을 수집하거나 배포물에 넣지 않는다.
