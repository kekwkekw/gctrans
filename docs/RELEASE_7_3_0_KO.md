# GCMod 7.3.0 릴리스 준비

PR #60의 설정 UI·전투 표시 통합은 main의 `729d523c3732c126092dfea68660a8037a80b02e`에 병합했다.
7.3.0 후보는 실기 검증한 build16의 동작을 유지하며 플러그인·어셈블리 버전과 시작 안내만 7.3.0으로 맞춘다.
이 문서는 릴리스 준비 기록이며 공개 완료를 뜻하지 않는다.

## 사용자 변경 사항

- 일반/CG 대화창 불투명도와 대화 글자 가독성 보정을 게임 옵션에서 조절한다.
- 프레임 제한은 홈 옵션의 화면 탭에서 30/60 FPS를 선택한다. 탭이 없는 시나리오 옵션에는 대화창 설정 아래에 있다.
- 선택한 값은 즉시 미리보기하며 설정 저장을 누르면 유지된다. 미저장 변경을 폐기하면 이전 저장값으로 돌아간다.
- CG 대화의 세 번째 줄을 화면과 배경 안에 배치한다.
- GCMod 전용 F3·F5·F6·F7·F8·F10 단축키를 제거했다. cfg나 번역 파일을 직접 수정한 뒤에는 게임을 재시작한다.
- 전투의 필요 열정·필요 HP·남은 CT 조합 문구를 처리하고 전투 Sprite 4개를 추가했다.
- 7.2.1 이후 main의 퀘스트·점수·공방·캐릭터 선택·던전 이력·AP 안내와 검수된 PC UI 문구, 시나리오 줄배치·용어 및 corpus 정비를 포함한다.

패키지에는 Master exact 34,388개, UI exact 14,073개, Novel 사전 1,939개, 이미지 대상 165개가 들어간다.
UI 수에는 유한 숫자·시간 조합이 포함된다. 전체 게임 완역이나 모든 장면의 실기 확인 수가 아니다.

## 설치와 설정 보존

신규 설치에는 `GCMod-7.3.0-ko-full-win-x64.zip`을 사용한다. 기존 7.x의 동일한 로더·Utility·한국어 폰트가
있는 설치에는 `GCMod-7.3.0-ko-update.zip`을 사용할 수 있다. 게임을 종료하고 기존 파일을 백업한다.
업데이트 시 **기존 `BepInEx/config/GCMod.cfg`를 보존**한다. ZIP 전체를 무조건 덮어쓰면 설정이 초기화된다.
기존 cfg가 없을 때만 패키지 기본 cfg를 설치한다. CLI 설치 도구도 기본적으로 기존 cfg 바이트를 보존한다.

신규 기본값은 일반/CG 불투명도 0%, 가독성 보정 켜짐, 60 FPS, 자간 0이다.
이미 설치된 사용자 설정은 유지한다. 제거된 단축키와 옛 기능의 cfg 키는 동작하지 않으며 강제 삭제하지 않는다.
신규 설정 UI와 실행 코드 보완에는 새 DLL이 필요하다. 번역 데이터 자동 갱신은 DLL·폰트·로더·설정을 갱신하지 않는다.

## 검증 범위

- PR #60 및 병합 main CI 통과. build16의 설정·일반/CG·대표 전투·재시작 실기는 [통합 검증 기록](BATTLE_UI_DISPLAY_20261103_KO.md)을 따른다.
- 7.3.0 Release 빌드 오류 0개, 기존 경고 6개. 전체 로컬 검사와 상태 36개·실제 설정 서비스 47개·렌더 어댑터 24개 검사를 통과했다.
- build16과 7.3.0의 439개 메서드, 13,405개 IL 명령을 대조했다. 시작 안내의 버전 문자열 두 곳 외 실행 명령·참조·지역 변수·예외 처리 구조가 동일하다. 나머지 변경은 버전 메타데이터와 상수다.
- 실기 build16 SHA-256: `9B579ABFF0A18A80A269C9AA5E5D8680E3F9F11CB5D046EF8B268F211841A2BF`.
- 7.3.0 DLL SHA-256: `9270A7AE1AD7E4D9149537937F2ECDA6794F4F0DECC02A2E8F019245064303B2`.
- 최종 7.3.0 DLL을 설치하고 시작·타이틀·홈 설정창을 확인했다. 공식 main manifest와 UI 14,073개·이미지 대상 165개를 로드했다. 30 FPS 미리보기 폐기 후 60 FPS 복원, 가독성 보정 미리보기의 탭 이동 폐기와 원래 값 복원을 확인했다. 오류·예외 0건이며 게임을 종료하고 원래 사용자 cfg 바이트를 복원했다.
- 이번 최종 확인은 기존 설치에서의 시작·설정창 점검이다. build16에서 확인한 전투·CG·저장 후 재시작 전체 절차와 순정 전체 재설치는 반복하지 않았다.

전체 설치본의 로더·Utility·한국어 폰트와 관련 소스·고지는 기존 7.2.1 공개본과 같은 검증된 바이트를 사용한다.
게임 본체·생성된 interop/cache·로그·인증 정보·개인 설정은 포함하지 않는다. ZIP의 파일 목록·크기·해시와 런타임 데이터는 별도 패키지 검사로 확인한다.
공개 전에는 이 준비 변경을 main에 반영하고 준비된 릴리스 초안을 공개한다.
