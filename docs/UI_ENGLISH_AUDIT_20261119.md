# 2026-11-19 영어 표기 조사

기준: `main dc57a9cd`의 영어/ASCII 원문 중 영문자를 포함하고 번역에 한글이 있는 쌍. UI 23쌍, Master 94쌍이며 두 목록은 중복된다. 화면 출현 횟수 또는 오류 수가 아니다. 일본어 혼합 문장과 이미지 로고는 제외했다. 조사 후 변경은 Normal/Hard 두 값뿐이다.
