## 재개 조건

- 게임 업데이트로 manifest token이나 설치 PC 파일이 바뀌면 해당 source만 새 snapshot으로
  수집한다. 이전 raw/history와 실패 근거를 유지하고 current/legacy를 섞지 않는다.
- 실제 플레이에서 미번역 문구가 확인되면 원문·화면·사용 경로를 기존 후보/조회 결과와
  대조한다. 이미 확보된 원문과 번역을 우선 재사용한다.
- 미해석 컴포넌트의 정확한 schema, 문자열 작성 함수, 크레딧 공식 독음 등 새 근거가 생기면
  그 항목만 재분류한다. 휴리스틱 문자열을 자동 승인하지 않는다.
- 사용자가 11장 전투 확인을 재개하면 [기존 호출 ID·검수 근거](BATTLE_NOVEL_FOLLOWUP_20261031_KO.md)를
  사용한다. 영문 번역은 사용자가 결정을 변경할 때만 재개한다.
- 추가 번역 반영은 기존 초벌 → PRO → preimage 검사 → apply/export 흐름을 따른다.
  crawler 종료를 이유로 서식 배포 승인, 전체 Knowledge 재구축, DLL 변경을 함께 처리하지 않는다.
