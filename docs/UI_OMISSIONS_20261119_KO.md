## 이전 조사에서 놓친 이유

수집 여부와 최종 표시 지원을 같은 것으로 판단하면 안 된다. 이번 텍스트의 상당수는 이미 추출·번역되어 있었지만, 게임이 숫자·날짜·Master 번역·문자열 조각을 조합한 결과가 사전 키와 달랐다. 이전의 원문/예시 coverage만으로 실제 화면을 충분히 검증했다고 본 점이 부족했다.

* 던전: prefab 예시는 `シーズンNN`이지만 실제 본문은 `시즌 28` 또는 `シーズン28`을 넣은 뒤 일본어 뒤 문장과 결합한다. `開催期間：{0} ~ {1}`도 최종 날짜로 바뀐다.
* ADF: 사전에는 `応援編成`, 배율 서식, 전투력 예시가 있어도 실제 값 `0/10`, `7.0`, `1,203,200`이 들어간 전체 키는 달랐다. 기존 번역의 누락보다 완성 문자열 지원의 공백이었다.
* 점수 피드: 플레이어 이름 + ` が ` + 이미 번역된 지구 이름 + ` で`로 구성한다. 사용자 이름과 알려지지 않은 서식을 일반 사전에 무차별 등록하지 않았던 경계가 이 표시 경로도 남겼다. 이번에는 해당 피드의 `TextLine1` 컴포넌트에만 연결 기호를 적용했다.
* 수령 기한: `2023/12/31 23:59` 같은 예시의 번역이 있어도 현재 날짜가 삽입된 완성 문자열과 일치하지 않았다.
* 상점 가격: 기존 숫자+단위 처리는 쉼표가 있는 `1,500/月` 형태를 처리하지 않았다. 이번에 관찰한 두 가격만 추가했다.
* 이미지: 상점 product/footer와 ADF `notinit/image_event_raid_label/erl*.dmm`는 기존 지구 카드 `BtArea*`와 다른 자산이다. 텍스트 추출 coverage는 이미지 내부 글자를 포함하지 않는다. 이전 회상 이미지 기록에도 미공개 미래 배너 4종 제외 및 composite artwork 범위 밖이 명시되어 있다. 현재 38페이지에 공개된 4종을 추가했다.

따라서 이번 사례를 "모든 원문이 아예 수집되지 않았다"고 결론 내리지는 않는다. 동시에 원문 수집 완료를 최종 화면의 일본어 잔존 0건으로 확대하지 않는다.

## 영어 표기

`Normal/Hard`는 `mTextConfig.ml_value[]`의 표시 번역에서 유래했다. 현재 Git 이력의 최초 통합은 `c5680eec1f63c9af4d545661f171d21e518c1b87`(2026-10-28)다. 표시 문자열을 `NORMAL/HARD`로 바꾸므로 난이도 선택 ID·enum·전투 수치는 그대로다. UI exporter도 Master에서 같은 표기를 생성한다.

[영어 표기 조사 전체 목록](UI_ENGLISH_AUDIT_20261119.md)에 UI 23쌍과 Master 94쌍을 기록했다. 이는 ASCII 원문에 영문자가 있고 한국어 번역이 들어간 정본의 고유 쌍을 조사한 수이며, 전체 화면에서 관찰한 개수나 번역 오류 수가 아니다. 일본어·영어 혼합 문장, 이미지 로고, 아직 수집되지 않은 새 콘텐츠는 이 수에 포함하지 않는다.

추가로 선택할 만한 원문 유지 후보는 `Very Hard`, `AUTO/MAX/NEW/ON/OFF/RANK`, 스테이지 이름의 `BATTLE…/CHALLENGE…/EXTRA…`다. 반면 색상·확인 버튼·능력치·스킬/의상 이름 번역은 일반적인 현지화로 볼 수 있어 일괄 오류 판정하지 않았다. 이번에는 요청한 Normal/Hard 외의 영어 표기를 임의로 되돌리지 않았다. ADF의 `VeryHard`와 Master의 `Very Hard`는 서로 다른 원문 키이며, 전자는 현재 화면에서 이미 영어로 표시된다.

## 표시 피드백 반영: 조사와 지구 디자인

초기 점수 피드 구현은 일본어 조사 부분을 가운데점으로 축약했다. 번역된 조사를 유지하는 형태로 수정해 `화가가 아테네스 근교에서`, `관장이 프란탄 지구에서`로 표시한다. 한글 마지막 음절의 받침으로 이/가를 선택하며, 발음을 알 수 없는 일본어·영문·기호로 끝난 이름에는 `이(가)`를 사용한다. rich-text 태그는 조사 판단에서만 제외하고 실제 이름의 bytes는 보존한다. 해당 피드의 `TextLine1`에만 적용한다.

지구 이미지는 프란탄·볼칸·이베르 3종을 유지하고 에그조티·노와르·전역·근교 4종을 같은 회갈색 글자 그라데이션, 밝은 테두리, 약한 그림자로 보정했다. 초기 4종은 밝은 글자/어두운 테두리가 섞여 있어 참조 스타일과 반대였다. 배경의 알파 그라데이션은 초기부터 원본과 같았으며, 수정 후에도 7종 모두 원본 알파와 정확히 일치한다. 글자 편집 영역 밖 RGBA도 원본과 같다. 내장 image_gen 참조 편집과 기존 크기/영역 정규화 경로를 사용했다. 이전 생성물과 원본은 로컬 및 Git 이력에 남겼다.

조사 복원 10개 이름 사례(한글 받침 유무·일본어·영문·내부 구분자·rich text·이모지), 기존 UI lookup 회귀 및 Release 빌드를 통과했다. 수정된 점수 문장과 이미지 4종은 이번 추가 수정 후 실제 게임 화면에서 다시 확인하기 전 상태이며, 최초 실기 결과를 최신 표시 검증으로 확대하지 않는다. 이미지 179종 수와 Knowledge·Names·Novel·Master/UI 번역값은 직전 PR 수정본 그대로다.
