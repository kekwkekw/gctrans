# Names Layer — 사용자 수락 검토안

이 문서는 검토용이며 제출·작성 자체가 승인 기록이 아니다. “좋아, 다음 PRO 작업”은 아래 항목의 자동 수락이 아니다.

## A. 기존 권고 유지 1,059개

QA_AMENDMENTS_5와 문맥 제한 6개를 제외한 exact key다. 기본안은 CUMULATIVE_RECOMMENDATIONS_1070.jsonl에 그대로 있다. 모든 표면 쌍과 345개 신호를 검토했지만 모든 문맥을 새로 읽은 것은 아니다. 기존 어휘/음역 대안은 보존된다. 공식 한국어명 또는 UI runtime 검증을 뜻하지 않는다.

## B. 수정 권고 5개 — 각각 별도 미승인

- **QA01-A001** `誘拐犯`: 유괴범 → **납치범**.
- **QA01-A002** `怪しげな男Ａ`: 수상한 남자A → **수상쩍은 남자A**.
- **QA01-A003** `怪しげな男Ｂ`: 수상한 남자B → **수상쩍은 남자B**.
- **QA01-A004** `義妹`: 양가의 여동생 → **양부모 집의 여동생**.
- **QA01-A005** `不審な男改め死の芸術家`: 수상한 남자 바꿔서 죽음의 예술가 → **죽음의 예술가가 된 수상한 남자**.

`QA01-A005`의 새 자연화는 기존 R34R-M007 승인 범위가 아니다. 이 항목을 수락하지 않으면 원본의 “수상한 남자 바꿔서 죽음의 예술가” 값이 보존된다. 다른 네 항목을 수락했다고 이 항목도 수락된 것으로 처리하지 않는다.

## C. 문맥 제한 6개 — 제한을 명시하고 수락하거나 보류

- `少年A` → **소년A**: SURFACE_ONLY_CONTEXT_EXCLUDED.
- `少年B` → **소년B**: SURFACE_ONLY_CONTEXT_EXCLUDED.
- `おばさん` → **아주머니**: PARTIAL_EXCERPT_ONLY.
- `お姉さん` → **아가씨**: PARTIAL_EXCERPT_ONLY.
- `画材屋店主` → **화구점 주인**: PARTIAL_EXCERPT_ONLY.
- `若者` → **젊은이**: PARTIAL_EXCERPT_ONLY.

이 여섯 표시명은 온전한 현재 문맥 검증이 끝난 것으로 쓸 수 없다. “제한을 알고 잠정 표시명을 수락”과 “추가 허용 원문 확인 전 보류”는 서로 다른 선택이다. 보류를 선택하면 1,070개 전체 accepted로 만들지 않는다. `お姉さん`의 아가씨는 일반 호칭의 잠정 선택이며 친족·나이·혼인 여부를 확정하지 않는다.

## 수락 기록에 필요한 정보

수락 대상 그룹/정확 key, B의 수락 amendment ID 또는 유지/대체값, C의 제한 수락 또는 보류를 기록한다. 새 한국어 값으로 바꾸면 그것도 별도의 결정이다. 실제 사용자 응답 원문과 시점/대상을 provenance로 남기며, 이 파일을 사용자 서명이나 응답 대신 사용하지 않는다.

수락 다음에도 production 배포는 별개다. Codex 정형 검증·candidate export → frozen snapshot 대비 별도 delta audit → immutable CDN/runtime gate → 별도 최종 merge/deploy 승인이 남는다. PR14와 main은 이 작업에서 조회하거나 수정하지 않았다.
