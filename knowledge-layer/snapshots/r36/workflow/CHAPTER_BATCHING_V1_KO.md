# 장 단위 PRO 의미 검수 운영 지침 v1 — R6 적용본

외부 요청 단위는 메인 스토리 **1장**, 내부 작업·완료 단위는 **1화**다. 일반 큐의 항목 수를 본문 수로 착각하지 않는다.

## 실행 순서
1. 현재 정본 ZIP 해시·schema·PASS·큐·NEXT_STEP·승인/충돌 보존을 확인한다.
2. 회차 순서대로 실제 source 제목과 첫 본문 raw부터 전체를 읽는다. 정규 본편은 raw1, 제목 없는 자산은 실제 first_body_raw_index를 따른다. 구조 분할 완료로 일반 큐에서 빠진 행도 읽는다.
3. 개별 원문/손번역의 의미·누락/추가·주체/대상·시점/양태·화자/청자·호칭/말투·용어/관계·태그/경계를 확인하고 행별 판단을 기록한다.
4. 명확한 오류와 문맥적 개선 후보를 나눈다. 확신이 낮으면 reviewing/관찰로 남긴다. 중간 신뢰도 제안을 확정 오역으로 설명하지 않는다.
5. 기존 등록부와 비교하여 같은 대상/교정은 새로 중복하지 않고 재확인 근거만 추가한다.
6. correction은 정확한 원본 block/field, Unicode codepoint offset, 원본 fragment/hash, 교정 fragment, 근거로 기록한다. 손번역 원본은 그대로 둔다.
7. 회차 전체의 근거·proposal·coverage·queue identity 검증 후에만 해당 회차 의미 1차 검수 완료를 표시한다.
8. 장 끝에서 이름·별칭·상대별 말투·관계·추측→후속 근거의 변화를 확인한다. 앞선 가설을 소급하여 확정 사실로 덮어쓰지 않는다.
9. 초·중·후반의 고위험 구간을 원문과 다시 대조하고 결과를 기록한다. 동일 검수자의 재대조는 독립 평가가 아니다.
10. 완료 범위만 큐에서 제거하고 원본·구조·참조·승인·충돌·runtime 미생성을 검증한 뒤 self-contained 체크포인트를 만든다.

## 품질/범위 안전장치
교정 밀도나 evidence 개수는 처리 누락을 찾는 보조 자료일 뿐 정확도 지표나 같은 분량의 교정 quota가 아니다. 오류를 억지로 만들지 않는다.
긴 회차/불명확한 화자/반복된 근거 누락/지시대상 혼동이 나타나면 범위를 줄인다. 이미 완료한 화까지만 반영하고 NEXT_STEP을 최초 미완료 자산의 실제 첫 미검수 raw로 설정한다(제목 없는 raw0 예외 포함). 진행 중인 화를 부분 저장하면 개별 coverage를 명시하고 완료라고 표시하지 않는다.
아직 읽지 않은 회차·제목·구조 분할 행을 일괄 승인하지 않는다. 원문의 태그를 새 의미 누락으로 혼동하지 않는다.

## 데이터/승인
canonical entity와 alias/reference/term/source/context를 분리한다. 말투는 speaker→target 및 직접호칭/제3자언급/자칭을 구분한다. 익명 화자는 로컬 장면 키로만 사용한다.
표면형 출현 검색은 이미 읽은 근거를 연결하는 보조 수단이다. substring 대체 규칙이 아니다.
`translation`은 승인 값만 허용한다. 현재 승인 term은 `アルテ → 아르테` 1개뿐이다. 기존 アングル/아테네스 경찰 계열 conflict를 유지한다.
추측·계획·거짓말·의도 해명·비유·작품 모델/창작자/소유자 관계는 구분한다. source 없는 JP 명칭, H BODY/Another/커뮤니티 chatter는 섞지 않는다.
CDN publish, fan corpus 일괄 교정, runtime export, GCMod 전환, 전역 substring 치환은 하지 않는다.

## 모델 단계
Very High: 해시·구조·파일·수량·계획 검증. 신규 일본어 의미 판단은 시작하지 않는다.
PRO: 본문 의미·뉘앙스·말투·관계·용어 판단. UI 모드/요금제 사용량을 추측해 보장하지 않는다.
