# 참고자료의 상태와 우선순위

`gc_PIPELINE_ROADMAP_v1_0_KO.md`는 2026-09-23 작성된 미래 설계 제안이다. 원문을 그대로 보존했다. R36 재개 관련 초기 문구나 이전 최우선 인계문 이름은 현재 진입 지시가 아니다. 새 프로젝트는 `NEW_PROJECT_PROMPT_KO.md`를 따른다.

`NAMES_4A_RESUME_NOTE_KO.md`는 보고서 조회에 근거한 상태 요약이며 원본 4-A ZIP을 대체하지 않는다.

`originals/`의 다섯 ZIP은 업로드 bytes 그대로다. filename의 다운로드 접미사만 제거했다. 원본의 `PENDING`, `export=false`, `main` 과거 SHA는 당시 기록이므로 수정하지 않았다. 현재 상태는 해당 범위의 더 나중 결정·최종 merge receipt·live GitHub metadata에 연결해서 읽는다.
