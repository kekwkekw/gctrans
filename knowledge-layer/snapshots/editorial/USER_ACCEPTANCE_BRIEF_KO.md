# 사용자 수락용 요약 — Post-R36 editorial 정책

**아직 적용·승인되지 않은 권고다.** 아래 정책을 한 번 수락하면 다음 매우 높음 작업에서 전체 안전 changeset을 준비할 수 있다. GitHub·GCMod·export·배포 권한은 포함하지 않는다.

## 권고 정책

| 범위 | 권고 |
|---|---|
| 말줄임표 | `…` 계열로 통일. 실제 대응 원문 길이를 보존하고, 일괄 6점→2자나 길이 반올림은 하지 않음 |
| 구조 대시 | `―` 계열로 통일. 연결·전환·발화 중단만 해당. 원문 run 길이를 보존 |
| 발음·외침·효과음 | 62회 보존. `그러---니까------`는 앞의 `---`만 보존하고 끝만 `――` |
| 마침표 후보 20행 | 19행에 `.`, `40106032/raw20` 자문형에 `?` |
| 대사·제목 | 마침표 일괄 추가·삭제하지 않음. `!?`와 기존 쉼·말더듬을 보존 |
| 공백 40회 | 부호 결합을 끊은 명시 10회만 제거, 나머지 30회 유지 |
| 보류·원문 이상·태그·괄호 | 정본의 위치를 우선하여 보호. 원래 block/span·태그열·묶음 검증 전 자동 확정 금지 |

## 별도 명시적으로 수락할 국소 권고

1. **10010209/raw26**: `나에게......` → `나에게――`. 다음 행의 공격으로 발화가 끊기는 장면.
2. **99900001/raw27**: `중...` → `중――`. 기획서를 쓰려는 시점에 다음 발화가 들어오는 전환.
3. **99900001/raw3**: `경영이 어렵다<br>` → `경영이 어렵다.<br>`. 줄바꿈 태그를 유지하고 첫 서술문도 마감.
4. **40112062/raw122**: `기뻐했다.\n고 들었다.` → `기뻐했다고 들었다.`. 상속된 전언 문장 분리 문제만 연결.
5. **40106032/raw20**: `그녀의 진의는 어디에 있는걸까` → `그녀의 진의는 어디에 있는걸까?`. 해당 자문형 1행만 물음표.

각 항목은 내용어·이름·승인된 의미 판단을 바꾸는 새 재번역이 아니다. 1·2·4는 부호가 전달하는 중단·전언의 기능을 명시적으로 검토한 예외다.

## 이번에 고친 조사 분류

“원문에 말줄임표 없음” 5회 중 3회는 줄바꿈 차이였고 2회만 대시 복원 대상으로 판단했다. 실제 원문 이상 위치인데 `source_anomaly=false`였던 11회는 자동 교정에서 제외했다. 기존 57회 외에 늘임·효과음 5회를 더 보호해 62회가 됐다.

## 사용자 결정에 사용할 문구

> 위 editorial 정책과 국소 예외 권고를 수락한다. 보류·원문 이상·태그·괄호 보호와 기존 의미 승인 범위를 유지한 채, 매우 높음으로 안전 changeset 생성·가상 합성·검증까지 진행한다. 실제 export·GitHub·GCMod·runtime·배포는 아직 하지 않는다.

구조용 Unicode glyph가 게임에서 같은 너비·타이핑 속도를 낸다고 검증한 상태는 아니다. runtime 확인은 이후 허가된 적용 단계의 별도 검사다.
