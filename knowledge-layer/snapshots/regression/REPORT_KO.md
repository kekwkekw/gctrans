## 8. 검증과 미검증의 경계

새 standalone 검사기는 별도 프로세스에서 PASS, 종료 코드 0, stderr 없음이었다.
ZIP에 1바이트를 덧붙인 음성 테스트는 정확히 `ZIP_IDENTITY` 게이트에서 차단했다.
다른 검사 실패를 목표 탐지 성공으로 세지 않았다.

처음 stdlib 검사기 실행 시 환경의 자동 site startup에서 무관한 artifact_tool warmup 경고가 있었다.
검사기 자체 결과는 PASS였으나 이를 stderr 없음으로 세지 않았다.
이후 `python -S -B`로 site plugin을 제외한 재실행을 기록했다.
이 작업은 스프레드시트 작업이나 검사 생략이 아니다.

미실행: 게임/Windows runtime, 폰트 glyph 폭, 타이핑 시간, 전체 시나리오 완주,
현재 게임 공식 원문 재조회, 새 CI 배포, GitHub review APPROVE/Ready/merge.
338개 모든 문장을 이번 턴에서 다시 전면 언어 검수했다고 하지 않는다.
보류 12행도 재검수하지 않았다.
